1. RESUMEN EJECUTIVO Y TESIS DEL PROYECTO
================================================================================

- Nombre del proyecto: Yucatán EWRS (Yucatán Hurricane Early Warning & Response System).
- Tipo de proyecto: MVP / Prototipo funcional interactivo construido en Python + Streamlit para la Coordinación Estatal de Protección Civil de Yucatán (PROCIVY), desarrollado en el contexto de una presentación de Economía Digital.
- Problema que aborda:
  Cuando un huracán impacta la península de Yucatán, existen cuatro grandes retos:
  1. Granularidad: Los boletines suelen ser regionales o estatales, pero el riesgo real varía drásticamente por municipio según elevación, vulnerabilidad a inundación, cercanía a la costa, capacidad de albergues y barreras lingüísticas.
  2. Idioma y canales: Gran parte de la población vulnerable en municipios del interior y oriente (como Tekax, Valladolid, Tizimín) habla Maya Yucateco, mientras que en zonas costeras y urbanas hay población hispanohablante y turistas/residentes angloparlantes. Redactar alertas manuales para múltiples canales (SMS Cell Broadcast, WhatsApp, Radio Comunitaria) y en 3 idiomas toma entre 30 y 60 minutos críticos.
  3. Triaje post-impacto: Tras el impacto, llegan decenas de reportes simultáneos (pacientes de diálisis aislados, carreteras bloqueadas, subestaciones inundadas, familias en techos) con recursos de brigadas limitados (Cruz Roja, SEMAR, SEDENA Plan DN-III-E, CFE, DIF/PROCIVY).
  4. Fragilidad tecnológica (Apagones y caída de telecomunicaciones): Durante un huracán categoría 4 o 5, la red eléctrica y el internet comercial fallan. Un sistema que dependa 100% de la nube colapsa justo cuando más se necesita.

- Tesis central ("Principio de Diseño"):
  "La Inteligencia Artificial es una CAPA DE AUMENTO (augmentation layer), NO un reemplazo."
  Los protocolos simples y probados (Cell Broadcast SMS, radio comunitaria AM/FM con generador, mapas impresos, perifoneo, radio VHF/HF y mantenimiento físico de pozos de absorción/drenaje) siguen siendo la columna vertebral. La capa de IA acelera y mejora la precisión cuando hay conectividad, y se degrada con gracia (graceful degradation) a ejecución local, plantillas preaprobadas offline y decisión humana (Human-in-the-Loop) cuando fallan la electricidad y las telecomunicaciones.

2. ARQUITECTURA FUNCIONAL: LAS 4 PESTAÑAS Y LA BARRA LATERAL
================================================================================

BARRA LATERAL (Simulador de Escenarios y Controles Operativos):
- Permite simular en tiempo real un huracán ajustando 4 parámetros:
  1. Categoría Saffir-Simpson (1 a 5).
  2. Lluvia acumulada en 24 horas (50 a 500 mm).
  3. Marea de tormenta / Storm surge (0.0 a 6.0 metros).
  4. Zona de impacto / trayectoria (North Coast, West Coast, East Coast, Inland).
- Controles de resiliencia:
  * "Offline / Demo Mode": Fuerza el uso de plantillas locales preaprobadas sin llamar a APIs externas.
  * "Simulate Power & Telecom Outage": Simula la caída de energía y telecomunicaciones comerciales para demostrar cómo responde y se degrada cada componente del sistema.
  * "Map renderer": Cambia entre mapa de calles online (OpenStreetMap) y mapa vectorial offline que no requiere servidor de teselas.
- "Model card" desplegable: Muestra las métricas reales del modelo RandomForest entrenado (R², MAE, tamaño de entrenamiento/prueba y gráfico de importancia global de variables).

PESTAÑA 1: 🗺️ Hyperlocal Risk Map (Mapa de Riesgo Hiperlocal)
- Qué hace: Evalúa en tiempo real el riesgo (0–100) y nivel (Low, Moderate, High, Critical) para 8 municipios clave de Yucatán:
  Progreso, Celestún, Hunucmá (Sisal), Río Lagartos, Tizimín (El Cuyo), Mérida, Valladolid y Tekax.
- Indicadores KPI superiores:
  1. Municipios en riesgo Alto/Crítico.
  2. Población expuesta estimada a peligros mortales.
  3. Estado de capacidad de albergues (% de utilización, camas demandadas vs. capacidad total, y alerta de municipios rebasados).
  4. Municipio de mayor riesgo actual y su puntaje.
- Visualizaciones:
  * Mapa interactivo con la trayectoria del huracán (línea morada) y burbujas por municipio escaladas y coloreadas por nivel de riesgo (con fallback automático a mapa vectorial offline).
  * Gráfico de barras horizontal con el ranking de riesgo (0–100) y umbrales (25, 50, 75).
  * Tabla desplegable de Explicabilidad ML ("Top 3 ML risk drivers per municipality"): Muestra para cada municipio cuáles son los 3 factores principales que impulsan su puntaje de riesgo en ese escenario (calculados mediante análisis de oclusión local).

PESTAÑA 2: 📣 Multilingual Alert Studio (Estudio de Alertas Multilingües)
- Qué hace: Genera alertas de emergencia adaptadas al municipio seleccionado y a su nivel de riesgo actual en 3 IDIOMAS:
  1. Español (es)
  2. Maya Yucateco (yua)
  3. Inglés (en)
  Y para 3 CANALES simultáneos por idioma (9 mensajes en total):
  1. Cell Broadcast SMS (estrictamente <= 160 caracteres).
  2. Mensaje comunitario de WhatsApp (con formato, pasos accionables y factor principal de riesgo).
  3. Guion de Radio Comunitaria de 30 segundos (~70–80 palabras, incluye conteo de palabras y tiempo estimado de lectura en voz alta).
- Cómo funciona por dentro:
  * Si el sistema está Online y tiene API key configurada (Google Gemini `gemini-2.5-flash` u OpenAI `gpt-4o-mini`), construye un prompt estructurado con el perfil de riesgo del municipio y solicita una salida JSON estricta.
  * Si está en modo Offline, si se simula apagón de telecomunicaciones, si no hay API key o si la API falla/tarda más de 20 segundos, hace fallback automático e instantáneo a la biblioteca de plantillas preaprobadas (`data/fallback_alerts.json`).
  * Incluye una advertencia ética/operativa indispensable: los textos en Maya Yucateco generados o asistidos por máquina son borradores que requieren validación por hablantes nativos e INDEMAYA antes de su difusión oficial.

PESTAÑA 3: 🚑 Post-Impact Triage (Triaje Post-Impacto con Human-in-the-Loop)
- Qué hace: Prioriza 10 incidentes simulados post-impacto y sugiere la asignación óptima de brigadas disponibles, exigiendo siempre la aprobación o modificación de un operador humano de PROCIVY.
- Cómo calcula la prioridad (0–100):
  Combina pesos ponderados:
  * Severidad del incidente (1–5): 45%
  * Personas vulnerables afectadas (escala logarítmica para que 4 pacientes de diálisis no sean opacados por un corte eléctrico masivo): 20%
  * Criticidad de infraestructura (1–5): 15%
  * Nivel de aislamiento/acceso (open=0.2, restricted=0.6, cut_off=1.0): 15%
  * Riesgo IA actual del municipio: 5%
  * Regla de salvamento de vida (Life-safety bonus): Si la severidad es 5 (peligro inminente de muerte), suma +10 puntos extra para saltar al frente de la cola.
- Asignación de brigadas (Greedy Allocator):
  Asigna unidades según prioridad descendente entre el inventario limitado de brigadas (Medical Evacuation, Water Rescue, Road Clearance, Power Restoration, Shelter Logistics, Search & Assessment). Si el tipo requerido se agota, busca una brigada alternativa compatible; si no quedan, lo pone en espera.
- Flujo Human-in-the-Loop (HITL):
  Ninguna unidad se desplaza sin firma humana. El operador puede aprobar ("Approve") la sugerencia de la IA o sobreescribirla ("Override") eligiendo otra brigada y registrando la razón (ej. conocimiento local de rutas abiertas). Todas las decisiones quedan registradas con marca de tiempo en el registro de auditoría ("Dispatch audit log").

PESTAÑA 4: ⚖️ Critical Check (Evaluación Crítica: Protocolos Base vs. Capa de IA)
- Qué hace: Compara lado a lado la resiliencia de 5 protocolos base no-IA contra 6 componentes de la capa de IA bajo dos condiciones: Operación Normal vs. Apagón Eléctrico y de Telecomunicaciones.
- Resultado cuantitativo:
  * En operación normal: Ambos operan al 100%.
  * Durante un apagón y caída de telecomunicaciones:
    - Los protocolos base retienen el 90% de su capacidad (la radio comunitaria con generador, los mapas impresos, el drenaje físico y el perifoneo/VHF siguen al 100%; Cell Broadcast se degrada al 50% mientras duran las baterías de respaldo de las antenas de 4 a 8 h).
    - La capa de IA cae al 33% de su capacidad (WhatsApp y la recepción digital de incidentes quedan Offline [0%]; el modelo ML local, las alertas con fallback a plantillas, el mapa vectorial offline y el triaje local pasan a estado Degraded [50%]).
- Tabla comparativa de valor agregado: Muestra qué aporta cada capa en granularidad, alcance lingüístico, tiempo de redacción (<1 min vs 30–60 min), priorización, dependencia de infraestructura, costo y confianza.

================================================================================
3. DETALLE TÉCNICO DE LOS MODELOS Y SERVICIOS
================================================================================

1. `models/risk_model.py` (Modelo ML Local + Explicabilidad por Oclusión)
   - Genera un dataset sintético determinista (`seed=42`, `N=1500` filas) cruzando los 8 municipios (con variación aleatoria de ±10% en sus indicadores estáticos para generalizar) con escenarios aleatorios de huracán.
   - Utiliza una función física plausible (`physical_risk_score`) que modela el decaimiento exponencial del viento, marea de tormenta y lluvia según la distancia en kilómetros a la polilínea de la trayectoria del huracán, combinada con la vulnerabilidad física y social (vulnerabilidad a inundación, elevación, porcentaje hablante de maya, brecha de albergues y densidad poblacional).
   - Entrena un `RandomForestRegressor` de scikit-learn (250 árboles, `max_depth=14`, `min_samples_leaf=2`) logrando un R² ≈ 0.94 y MAE ≈ 3.7 puntos.
   - Guarda el artefacto entrenado en `models/artifacts/risk_model.joblib` para carga instantánea.
   - Explicabilidad local (`explain_local`): Para cada municipio en el escenario actual, reemplaza una por una cada una de las 10 variables por su media de entrenamiento y mide cuántos puntos cae el riesgo predicho. Los 3 factores con mayor caída se reportan como los "Top 3 risk drivers" de ese municipio.

2. `services/alert_generator.py` (Generador Multilingüe + Fallback Resiliente)
   - Soporta Google Gemini (`google-genai`) y OpenAI (`openai`) configurables mediante `.env`.
   - Impone límite estricto de 160 caracteres para SMS Cell Broadcast (`enforce_sms_limit`).
   - Garantiza cero caídas en presentaciones en vivo: cualquier excepción de red, falta de clave API, timeout o modo offline devuelve instantáneamente las plantillas rellenadas desde `data/fallback_alerts.json` e informa la razón exacta del fallback en la interfaz.

3. `services/triage_engine.py` (Motor de Priorización y Auditoría HITL)
   - Calcula `priority_score` (0–100) y clasifica en bandas operativas (`P1 – Immediate` >= 75, `P2 – Urgent` >= 55, `P3 – Priority` >= 35, `P4 – Routine` < 35).
   - Ejecuta asignación voraz (`suggest_allocation`) respetando límites de unidades y matriz de reemplazos (`ALTERNATES`).
   - Gestiona el estado de decisiones y bitácora de auditoría en `st.session_state`.

def _hover(df: pd.DataFrame) -> pd.DataFrame:
    """Add formatted hover columns."""
    d = df.copy()
    d["Exposed"] = d["exposed_population"].map("{:,}".format)
    d["Population"] = d["population"].map("{:,}".format)
    d["size"] = 8 + d["risk_score"] / 3.5
    return d


def street_map(df: pd.DataFrame, zone: str) -> go.Figure:
    """OpenStreetMap tile map (scatter_mapbox, or scatter_map on Plotly >= 6)."""
    d = _hover(df)
    track = LANDFALL_TRACKS[zone]
    common = dict(
        lat="lat", lon="lon", color="risk_level", size="size", size_max=26,
        color_discrete_map=RISK_COLORS, category_orders={"risk_level": RISK_ORDER},
        hover_name="name", hover_data={"risk_score": True, "Exposed": True, "Population": True,
                                       "size": False, "lat": False, "lon": False, "risk_level": False},
        zoom=6.4, center={"lat": 20.95, "lon": -89.0}, height=520,
    )
    with warnings.catch_warnings():
        warnings.simplefilter("ignore")
        if hasattr(px, "scatter_mapbox"):
            fig = px.scatter_mapbox(d, mapbox_style="open-street-map", **common)
            fig.add_trace(go.Scattermapbox(lat=[p[0] for p in track], lon=[p[1] for p in track], mode="lines",
                                           line=dict(width=3, color="#7C3AED"), name="Storm track"))
        else:
            fig = px.scatter_map(d, map_style="open-street-map", **common)
            fig.add_trace(go.Scattermap(lat=[p[0] for p in track], lon=[p[1] for p in track], mode="lines",
                                        line=dict(width=3, color="#7C3AED"), name="Storm track"))
    fig.update_layout(margin=dict(l=0, r=0, t=0, b=0), legend=dict(title="Risk level", orientation="h", y=-0.02))
    return fig

def load_municipalities(path: Path = DATA_PATH) -> tuple[pd.DataFrame, dict[str, Any]]:
    """Load municipality baseline indicators and metadata.

    Returns:
        A DataFrame with one row per municipality and the metadata dictionary.
    """

def _to_km(lat: float, lon: float, ref_lat: float) -> tuple[float, float]:
    """Project lat/lon to a local equirectangular plane in kilometres."""
    return lon * 111.32 * math.cos(math.radians(ref_lat)), lat * 110.57


def distance_to_track_km(lat: float, lon: float, landfall_zone: str) -> float:
    """Minimum distance (km) from a point to the storm-track polyline."""
    track = LANDFALL_TRACKS[landfall_zone]
    px, py = _to_km(lat, lon, lat)
    best = math.inf
    for (lat1, lon1), (lat2, lon2) in zip(track[:-1], track[1:]):
        ax, ay = _to_km(lat1, lon1, lat)
        bx, by = _to_km(lat2, lon2, lat)
        dx, dy = bx - ax, by - ay
        seg_len2 = dx * dx + dy * dy
        t = 0.0 if seg_len2 == 0 else max(0.0, min(1.0, ((px - ax) * dx + (py - ay) * dy) / seg_len2))
        cx, cy = ax + t * dx, ay + t * dy
        best = min(best, math.hypot(px - cx, py - cy))
    return best


def risk_level(score: float) -> str:
    """Map a 0–100 risk score to a categorical risk level."""
    for threshold, label in RISK_LEVELS:
        if score < threshold:
            return label
    return "Critical"


# --------------------------------------------------------------------------- #
# Synthetic ground truth
# --------------------------------------------------------------------------- #
def physical_risk_score(df: pd.DataFrame) -> np.ndarray:
    """Physically plausible 'ground-truth' risk formula used to label data.

    Combines wind, storm-surge and rainfall hazards (each decaying with
    distance to the track) with social and physical vulnerability.
    """
    cat = df["category"].to_numpy(float)
    rain = df["rainfall_mm_24h"].to_numpy(float)
    surge = df["storm_surge_m"].to_numpy(float)
    dist = df["distance_to_track_km"].to_numpy(float)
    coastal = df["coastal"].to_numpy(float)
    flood = df["flood_vulnerability"].to_numpy(float)
    elev = df["elevation_m"].to_numpy(float)
    maya = df["maya_speaking_pct"].to_numpy(float) / 100.0
    shelter = df["shelter_ratio"].to_numpy(float)
    logpop = df["log_population"].to_numpy(float)

    wind = (cat / 5.0) ** 1.6 * np.exp(-dist / 110.0)
    elev_factor = np.clip(1.0 - elev / 10.0, 0.0, 1.0)
    surge_h = coastal * np.clip(surge / 6.0, 0.0, 1.0) * np.exp(-dist / 70.0) * (0.3 + 0.7 * elev_factor)
    rain_h = np.clip(rain / 500.0, 0.0, 1.0) * (0.4 + 0.6 * flood) * np.exp(-dist / 260.0)

    hazard = np.clip(0.40 * wind + 0.35 * surge_h + 0.35 * rain_h, 0.0, 1.0)
    shelter_gap = np.clip(1.0 - shelter / 0.20, 0.0, 1.0)
    pop_density = np.clip((logpop - 8.0) / 6.0, 0.0, 1.0)
    vulnerability = 0.45 * flood + 0.20 * maya + 0.20 * shelter_gap + 0.15 * pop_density

    return np.clip(100.0 * hazard * (0.75 + 0.9 * vulnerability) * 1.25, 0.0, 100.0)


def generate_synthetic_dataset(n_samples: int = N_SAMPLES, seed: int = RANDOM_SEED) -> pd.DataFrame:
    """Create a deterministic synthetic training dataset.

    Each row samples one of the 8 municipalities (with ±10% jitter on static
    indicators so the model generalises) and a random hurricane scenario.
    """
    rng = np.random.default_rng(seed)
    munis, _ = load_municipalities()
    idx = rng.integers(0, len(munis), n_samples)
    base = munis.iloc[idx].reset_index(drop=True)

    def jitter(values: pd.Series, scale: float = 0.10) -> np.ndarray:
        return values.to_numpy(float) * rng.uniform(1 - scale, 1 + scale, n_samples)

    population = jitter(base["population"])
    df = pd.DataFrame(
        {
            "category": rng.integers(1, 6, n_samples),
            "rainfall_mm_24h": rng.uniform(40, 500, n_samples).round(0),
            "storm_surge_m": rng.uniform(0.0, 6.0, n_samples).round(2),
            "distance_to_track_km": np.clip(rng.gamma(2.0, 60.0, n_samples), 0, 350).round(1),
            "coastal": base["coastal"].astype(int).to_numpy(),
            "flood_vulnerability": np.clip(jitter(base["flood_vulnerability"]), 0, 1),
            "elevation_m": np.clip(jitter(base["elevation_m"], 0.25), 0.5, None),
            "maya_speaking_pct": np.clip(jitter(base["maya_speaking_pct"]), 0, 100),
            "shelter_ratio": jitter(base["shelter_capacity"]) / population,
            "log_population": np.log(population),
        }
    )
    noise = rng.normal(0.0, 2.5, n_samples)
    df["risk_score"] = np.clip(physical_risk_score(df) + noise, 0.0, 100.0)
    return df


# --------------------------------------------------------------------------- #
# Training / persistence
# --------------------------------------------------------------------------- #
def train_model(save: bool = True) -> dict[str, Any]:
    """Train the RandomForest risk model and optionally persist it.

    Returns:
        Artifact dictionary with the model, feature list, baseline means,
        evaluation metrics and global feature importances.
    """
    df = generate_synthetic_dataset()
    X, y = df[FEATURES], df["risk_score"]
    X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2, random_state=RANDOM_SEED)

    model = RandomForestRegressor(
        n_estimators=250, max_depth=14, min_samples_leaf=2, random_state=RANDOM_SEED, n_jobs=-1
    )
    model.fit(X_train, y_train)
    preds = model.predict(X_test)

    artifact: dict[str, Any] = {
        "version": MODEL_VERSION,
        "model": model,
        "features": FEATURES,
        "feature_means": X_train.mean().to_dict(),
        "metrics": {
            "r2": float(r2_score(y_test, preds)),
            "mae": float(mean_absolute_error(y_test, preds)),
            "n_train": int(len(X_train)),
            "n_test": int(len(X_test)),
        },
        "feature_importances": dict(zip(FEATURES, model.feature_importances_.round(4).tolist())),
    }
    if save:
        ARTIFACT_DIR.mkdir(parents=True, exist_ok=True)
        joblib.dump(artifact, ARTIFACT_PATH)
    return artifact


def load_model(retrain_if_missing: bool = True) -> dict[str, Any]:
    """Load the persisted artifact, retraining if it is missing or stale."""
    if ARTIFACT_PATH.exists():
        try:
            artifact = joblib.load(ARTIFACT_PATH)
            if artifact.get("version") == MODEL_VERSION and artifact.get("features") == FEATURES:
                return artifact
        except Exception:  # corrupted or incompatible pickle -> retrain
            pass
    if not retrain_if_missing:
        raise FileNotFoundError(f"No valid model artifact at {ARTIFACT_PATH}")
    return train_model(save=True)

def build_feature_frame(scenario: Scenario, munis: pd.DataFrame) -> pd.DataFrame:
    """Combine a scenario with municipality indicators into model features."""
    return pd.DataFrame(
        {
            "category": scenario.category,
            "rainfall_mm_24h": scenario.rainfall_mm_24h,
            "storm_surge_m": scenario.storm_surge_m,
            "distance_to_track_km": [
                distance_to_track_km(r.lat, r.lon, scenario.landfall_zone) for r in munis.itertuples()
            ],
            "coastal": munis["coastal"].astype(int),
            "flood_vulnerability": munis["flood_vulnerability"],
            "elevation_m": munis["elevation_m"],
            "maya_speaking_pct": munis["maya_speaking_pct"],
            "shelter_ratio": munis["shelter_capacity"] / munis["population"],
            "log_population": np.log(munis["population"]),
        }
    )[FEATURES]


def _describe_factor(feature: str, row: pd.Series) -> str:
    """Human-readable label for a contributing factor with its value."""
    value = row[feature]
    detail = {
        "category": f"Category {int(value)}",
        "rainfall_mm_24h": f"{value:.0f} mm/24h",
        "storm_surge_m": f"{value:.1f} m surge",
        "distance_to_track_km": f"{value:.0f} km from track",
        "coastal": "coastline",
        "flood_vulnerability": f"index {value:.2f}",
        "elevation_m": f"{value:.0f} m a.s.l.",
        "maya_speaking_pct": f"{value:.0f}% Maya-speaking",
        "shelter_ratio": f"{value * 100:.0f} beds / 100 residents",
        "log_population": f"{math.exp(value):,.0f} residents",
    }[feature]
    return f"{FEATURE_LABELS[feature]} ({detail})"


def explain_local(artifact: dict[str, Any], X: pd.DataFrame, top_k: int = 3) -> list[list[dict[str, Any]]]:
    """Occlusion-based local explanation of each prediction.

    For each feature, replace it with its training mean and record how much the
    prediction falls. Returns the ``top_k`` positive drivers per row.
    """
    model = artifact["model"]
    base_pred = model.predict(X)
    contributions = np.zeros((len(X), len(FEATURES)))
    for j, feat in enumerate(FEATURES):
        X_ref = X.copy()
        X_ref[feat] = artifact["feature_means"][feat]
        contributions[:, j] = base_pred - model.predict(X_ref)

    explanations: list[list[dict[str, Any]]] = []
    for i in range(len(X)):
        order = np.argsort(-contributions[i])[:top_k]
        explanations.append(
            [
                {
                    "feature": FEATURES[j],
                    "label": _describe_factor(FEATURES[j], X.iloc[i]),
                    "contribution": round(float(contributions[i, j]), 1),
                }
                for j in order
            ]
        )
    return explanations


def estimate_exposed_population(population: float, score: float, coastal: bool) -> int:
    """Estimate residents directly exposed to life-threatening hazards."""
    fraction = (score / 100.0) ** 2 * (0.85 if coastal else 0.30)
    return int(round(population * fraction, -1))


def predict_municipality_risks(scenario: Scenario | dict[str, Any], artifact: dict[str, Any] | None = None) -> pd.DataFrame:
    """Predict hyperlocal risk for every municipality under a scenario.

    Args:
        scenario: A :class:`Scenario` or dict with ``category``,
            ``rainfall_mm_24h``, ``storm_surge_m`` and ``landfall_zone``.
        artifact: Optional pre-loaded model artifact.

    Returns:
        DataFrame with municipality info plus ``risk_score``, ``risk_level``,
        ``distance_to_track_km``, ``exposed_population``, ``shelter_demand``,
        ``top_factors`` (list of dicts) and ``top_factors_text``.
    """
    if isinstance(scenario, dict):
        scenario = Scenario(**scenario)
    artifact = artifact or load_model()
    munis, _ = load_municipalities()
    X = build_feature_frame(scenario, munis)

    scores = np.clip(artifact["model"].predict(X), 0, 100).round(1)
    explanations = explain_local(artifact, X)

    out = munis.copy()
    out["distance_to_track_km"] = X["distance_to_track_km"].round(0).to_numpy()
    out["risk_score"] = scores
    out["risk_level"] = [risk_level(s) for s in scores]
    out["exposed_population"] = [
        estimate_exposed_population(p, s, c) for p, s, c in zip(out["population"], scores, out["coastal"])
    ]
    out["shelter_demand"] = (out["exposed_population"] * SHELTER_SEEKING_RATE).round().astype(int)
    out["top_factors"] = explanations
    out["top_factors_text"] = [" · ".join(f["label"] for f in exp) for exp in explanations]
    return out.sort_values("risk_score", ascending=False).reset_index(drop=True)


def scenario_to_dict(scenario: Scenario) -> dict[str, Any]:
    """Serialise a scenario (handy for caching keys and prompts)."""
    return asdict(scenario)


if __name__ == "__main__":
    art = train_model(save=True)
    print(f"Model saved to {ARTIFACT_PATH}")
    print("Metrics:", art["metrics"])
    demo = predict_municipality_risks(Scenario(4, 300, 3.5, "North Coast"), art)
    print(demo[["name", "risk_score", "risk_level", "exposed_population", "top_factors_text"]].to_string())

"""Multilingual emergency alert generation (Spanish, Yucatec Maya, English).

Alerts are produced for three channels — Cell Broadcast SMS (<=160 chars),
WhatsApp community message and a 30-second community radio script.

Generation strategy:
    1. If Online Mode is active and an API key is configured, call the

    2. Otherwise — or if the call fails, times out or returns malformed

from __future__ import annotations

import json
import os
import re
from dataclasses import dataclass, field
from pathlib import Path
from typing import Any

from dotenv import load_dotenv

ROOT = Path(__file__).resolve().parent.parent
FALLBACK_PATH = ROOT / "data" / "fallback_alerts.json"
load_dotenv(ROOT / ".env")

LANGUAGES: dict[str, str] = {"es": "Spanish", "yua": "Yucatec Maya", "en": "English"}
CHANNELS: dict[str, str] = {
    "sms": "Cell Broadcast SMS",
    "whatsapp": "WhatsApp Community Message",
    "radio": "30-sec Community Radio Script",
}
SMS_MAX_CHARS = 160
HOTLINE = "911"
LLM_TIMEOUT_S = 20

STATUS_LIVE = "Live LLM"
STATUS_FALLBACK = "Offline Fallback"

MAYA_DISCLAIMER = (
    "Yucatec Maya outputs are machine-assisted drafts. They must be validated by native speakers "
    "and INDEMAYA (Instituto para el Desarrollo de la Cultura Maya del Estado de Yucatán) before any "
    "real-world deployment."

@dataclass
class AlertResult:
    """Generated alert bundle and its provenance."""

    municipality: str
    risk_level: str
    alerts: dict[str, dict[str, str]]  # {lang: {channel: text}}
    status: str  # STATUS_LIVE or STATUS_FALLBACK
    provider: str
    reason: str = ""
    warnings: list[str] = field(default_factory=list)


# --------------------------------------------------------------------------- #
# Configuration helpers
# --------------------------------------------------------------------------- #
def get_llm_config() -> dict[str, str | None]:
    """Read LLM provider settings from the environment / ``.env``."""
    provider = (os.getenv("LLM_PROVIDER") or "gemini").strip().lower()
    if provider == "openai":
        key, model = os.getenv("OPENAI_API_KEY"), os.getenv("OPENAI_MODEL") or "gpt-4o-mini"
    else:
        provider = "gemini"
        key, model = os.getenv("GEMINI_API_KEY"), os.getenv("GEMINI_MODEL") or "gemini-2.5-flash"
    return {"provider": provider, "api_key": (key or "").strip() or None, "model": model}


def llm_available() -> bool:
    """True when an API key for the configured provider is present."""
    return get_llm_config()["api_key"] is not None


def load_fallback_library(path: Path = FALLBACK_PATH) -> dict[str, Any]:
    """Load the offline template library."""
    with open(path, encoding="utf-8") as fh:
        return json.load(fh)


# --------------------------------------------------------------------------- #
# Formatting helpers
# --------------------------------------------------------------------------- #
def _short_factor(profile: dict[str, Any]) -> str:
    """Main risk driver label without the parenthesised value."""
    factors = profile.get("top_factors") or []
    if not factors:
        return "hurricane hazard"
    return re.sub(r"\s*\(.*\)$", "", factors[0]["label"])


def enforce_sms_limit(text: str, limit: int = SMS_MAX_CHARS) -> str:
    """Collapse whitespace and trim an SMS to ``limit`` characters."""
    text = re.sub(r"\s+", " ", text).strip()
    if len(text) <= limit:
        return text
    return text[: limit - 1].rstrip(" ,.;:") + "…"


def _template_values(profile: dict[str, Any], scenario: dict[str, Any], lang: str, labels: dict[str, Any]) -> dict[str, str]:
    """Placeholder values for template injection in a given language."""
    level = profile["risk_level"]
    return {
        "municipality": profile["name"],
        "locality": profile.get("locality", profile["name"]),
        "category": str(scenario["category"]),
        "risk_level": labels.get(lang, {}).get(level, level.upper()),
        "risk_score": f"{profile['risk_score']:.0f}",
        "rainfall": f"{scenario['rainfall_mm_24h']:.0f}",
        "surge": f"{scenario['storm_surge_m']:.1f}",
        "exposed": f"{profile.get('exposed_population', 0):,}",
        "top_factor": _short_factor(profile),
        "hotline": HOTLINE,
    }


# --------------------------------------------------------------------------- #
# Offline fallback
# --------------------------------------------------------------------------- #
def generate_fallback_alerts(profile: dict[str, Any], scenario: dict[str, Any], reason: str = "Offline / Demo Mode") -> AlertResult:
    """Fill pre-approved templates with municipality / risk values."""
    library = load_fallback_library()
    level = profile["risk_level"]
    templates = library["templates"].get(level) or library["templates"]["High"]
    labels = library.get("risk_labels", {})

    alerts: dict[str, dict[str, str]] = {}
    for lang in LANGUAGES:
        values = _template_values(profile, scenario, lang, labels)
        alerts[lang] = {ch: templates[lang][ch].format(**values) for ch in CHANNELS}
        alerts[lang]["sms"] = enforce_sms_limit(alerts[lang]["sms"])

    return AlertResult(
        municipality=profile["name"],
        risk_level=level,
        alerts=alerts,
        status=STATUS_FALLBACK,
        provider="Pre-approved templates (data/fallback_alerts.json)",
        reason=reason,
    )

# Live LLM
# --------------------------------------------------------------------------- #
SYSTEM_PROMPT = (
    "You are an emergency communications officer for PROCIVY (Protección Civil de Yucatán, Mexico). "
    "Write clear, calm, actionable hurricane alerts for the public. Never invent shelter names, "
    "addresses or phone numbers other than the hotline provided. Use plain language suitable for "
    "low-literacy audiences. Respond ONLY with valid JSON."
)


def build_prompt(profile: dict[str, Any], scenario: dict[str, Any]) -> str:
    """Construct the user prompt describing the risk profile and output schema."""
    factors = "; ".join(f["label"] for f in profile.get("top_factors", [])) or "n/a"
    return f"""
Generate hurricane emergency alerts for the municipality of {profile['name']} (locality: {profile.get('locality', profile['name'])}), Yucatán, Mexico.

RISK PROFILE
- Hurricane category: {scenario['category']}
- Rainfall: {scenario['rainfall_mm_24h']:.0f} mm in 24 h
- Storm surge: {scenario['storm_surge_m']:.1f} m
- Landfall zone: {scenario['landfall_zone']}
- AI risk score: {profile['risk_score']:.0f}/100 → risk level {profile['risk_level']}
- Estimated exposed population: {profile.get('exposed_population', 0):,}
- Top risk drivers: {factors}
- Emergency hotline: {HOTLINE}

ACTION GUIDANCE BY LEVEL
- Critical: mandatory immediate evacuation to the nearest official shelter.
- High: prepare to evacuate; low-lying/coastal residents go to shelter now.
- Moderate: prepare go-bag, locate shelter, clear drains.
- Low: stay informed, review family plan.

OUTPUT: a JSON object with keys "es" (Spanish), "yua" (Yucatec Maya), "en" (English).
Each language maps to an object with keys:
- "sms": Cell Broadcast text, MAXIMUM 160 characters, starting with "PROCIVY".
- "whatsapp": community message (80–140 words), may use emojis and *bold*, numbered actions.
- "radio": 30-second radio script (~70–80 words), begin with "[ALERT TONE]" or equivalent.
For Yucatec Maya use natural Yucatec Maya; keep "PROCIVY", the hotline and numbers unchanged.
""".strip()


def _call_gemini(prompt: str, api_key: str, model: str) -> str:
    """Call Google Gemini via ``google-genai`` and return raw text."""
    from google import genai
    from google.genai import types

    client = genai.Client(api_key=api_key, http_options=types.HttpOptions(timeout=LLM_TIMEOUT_S * 1000))
    response = client.models.generate_content(
        model=model,
        contents=prompt,
        config=types.GenerateContentConfig(
            system_instruction=SYSTEM_PROMPT,
            temperature=0.4,
            response_mime_type="application/json",
        ),
    )
    return response.text or ""


def _call_openai(prompt: str, api_key: str, model: str) -> str:
    """Call OpenAI Chat Completions and return raw text."""
    from openai import OpenAI

    client = OpenAI(api_key=api_key, timeout=LLM_TIMEOUT_S, max_retries=1)
    response = client.chat.completions.create(
        model=model,
        temperature=0.4,
        response_format={"type": "json_object"},
        messages=[{"role": "system", "content": SYSTEM_PROMPT}, {"role": "user", "content": prompt}],
    )
    return response.choices[0].message.content or ""


def parse_llm_output(raw: str) -> dict[str, dict[str, str]]:
    """Parse and validate the LLM JSON payload.

    Raises:
        ValueError: if any language/channel is missing or empty.
    """
    cleaned = re.sub(r"^```(?:json)?|```$", "", raw.strip(), flags=re.MULTILINE).strip()
    data = json.loads(cleaned)
    alerts: dict[str, dict[str, str]] = {}
    for lang in LANGUAGES:
        block = data.get(lang)
        if not isinstance(block, dict):
            raise ValueError(f"Missing language block '{lang}'")
        alerts[lang] = {}
        for ch in CHANNELS:
            text = str(block.get(ch, "")).strip()
            if not text:
                raise ValueError(f"Missing '{ch}' text for '{lang}'")
            alerts[lang][ch] = text
    return alerts


def generate_llm_alerts(profile: dict[str, Any], scenario: dict[str, Any]) -> AlertResult:
    """Generate alerts with the configured LLM (raises on any failure)."""
    cfg = get_llm_config()
    if not cfg["api_key"]:
        raise RuntimeError("No API key configured")
    prompt = build_prompt(profile, scenario)
    caller = _call_openai if cfg["provider"] == "openai" else _call_gemini
    alerts = parse_llm_output(caller(prompt, cfg["api_key"], cfg["model"]))

    warnings: list[str] = []
    for lang in LANGUAGES:
        original = alerts[lang]["sms"]
        alerts[lang]["sms"] = enforce_sms_limit(original)
        if len(re.sub(r"\s+", " ", original).strip()) > SMS_MAX_CHARS:
            warnings.append(f"{LANGUAGES[lang]} SMS exceeded {SMS_MAX_CHARS} chars and was trimmed.")

    return AlertResult(
        municipality=profile["name"],
        risk_level=profile["risk_level"],
        alerts=alerts,
        status=STATUS_LIVE,
        provider=f"{cfg['provider'].title()} · {cfg['model']}",
        warnings=warnings,
    )


# --------------------------------------------------------------------------- #
# Public entry point
# --------------------------------------------------------------------------- #
def generate_alerts(profile: dict[str, Any], scenario: dict[str, Any], online: bool = True) -> AlertResult:
    """Generate multilingual alerts with automatic offline fallback.

    Args:
        profile: Municipality risk profile (row from ``predict_municipality_risks``).
        scenario: Scenario dictionary (category, rainfall, surge, landfall zone).
        online: False when Offline / Demo Mode or a telecom outage is active.

    Returns:
        An :class:`AlertResult`; never raises for LLM problems.
    """
    if not online:
        return generate_fallback_alerts(profile, scenario, reason="Offline / Demo Mode active")
    if not llm_available():
        return generate_fallback_alerts(profile, scenario, reason="No LLM API key configured")
    try:
        return generate_llm_alerts(profile, scenario)
    except Exception as exc:  # network, timeout, quota, malformed JSON, missing SDK…
        detail = f"{type(exc).__name__}: {exc}"
        return generate_fallback_alerts(profile, scenario, reason=f"LLM call failed → {detail[:160]}")

def load_incident_data(path: Path = INCIDENTS_PATH) -> tuple[pd.DataFrame, list[dict[str, Any]]]:
    """Load incident reports and the brigade roster."""
    with open(path, encoding="utf-8") as fh:
        payload = json.load(fh)
    return pd.DataFrame(payload["incidents"]), payload["brigades"]


def priority_band(score: float) -> str:
    """Translate a priority score into an operational band."""
    if score >= 75:
        return "P1 – Immediate"
    if score >= 55:
        return "P2 – Urgent"
    if score >= 35:
        return "P3 – Priority"
    return "P4 – Routine"


def score_incidents(incidents: pd.DataFrame, area_risk: dict[str, float] | None = None) -> pd.DataFrame:
    """Compute a 0–100 priority score for every incident.

    Args:
        incidents: Incident reports.
        area_risk: Optional mapping municipality -> AI risk score (0–100).

    Returns:
        Copy of ``incidents`` with ``priority_score`` and ``priority_band``,
        sorted by descending priority.
    """
    area_risk = area_risk or {}
    df = incidents.copy()
    # Log scale so a handful of dialysis patients is not dwarfed by a city outage.
    vuln_norm = df["vulnerable_people"].apply(lambda v: min(math.log10(v + 1) / math.log10(5000), 1.0))
    df["priority_score"] = 100 * (
        WEIGHTS["severity"] * df["severity"] / 5
        + WEIGHTS["vulnerable"] * vuln_norm
        + WEIGHTS["infrastructure"] * df["infrastructure_criticality"] / 5
        + WEIGHTS["access"] * df["access"].map(ACCESS_SCORES).fillna(0.5)
        + WEIGHTS["area_risk"] * df["municipality"].map(area_risk).fillna(50) / 100
    )
    df.loc[df["severity"] >= 5, "priority_score"] += LIFE_SAFETY_BONUS
    df["priority_score"] = df["priority_score"].clip(upper=100).round(1)
    df["priority_band"] = df["priority_score"].apply(priority_band)
    return df.sort_values(["priority_score", "severity"], ascending=False).reset_index(drop=True)


def suggest_allocation(scored: pd.DataFrame, brigades: list[dict[str, Any]]) -> pd.DataFrame:
    """Greedy AI brigade suggestion in priority order.

    Uses the required brigade type when units remain, otherwise an alternate
    type, otherwise queues the incident.
    """
    available = {b["type"]: int(b["units"]) for b in brigades}
    agencies = {b["type"]: b["agency"] for b in brigades}
    suggestions, rationales = [], []
    for row in scored.itertuples():
        wanted = row.required_brigade
        chosen, why = None, ""
        if available.get(wanted, 0) > 0:
            chosen, why = wanted, "Matches required capability"
        else:
            for alt in ALTERNATES.get(wanted, []):
                if available.get(alt, 0) > 0:
                    chosen, why = alt, f"{wanted} units exhausted → nearest alternate capability"
                    break
        if chosen:
            available[chosen] -= 1
            suggestions.append(f"{chosen} ({agencies[chosen]})")
        else:
            suggestions.append(UNASSIGNED)
            why = f"All {wanted} and alternate units committed to higher-priority incidents"
        rationales.append(why)
    out = scored.copy()
    out["ai_suggestion"] = suggestions
    out["ai_rationale"] = rationales
    return out


def brigade_options(brigades: list[dict[str, Any]]) -> list[str]:
    """Labels an operator can choose from when overriding."""
    return [f"{b['type']} ({b['agency']})" for b in brigades] + [UNASSIGNED, "Hold – request more information"]


def init_decisions(incident_ids: list[str], state: dict[str, Any]) -> None:
    """Ensure every incident has a decision record in session state."""
    decisions = state.setdefault("triage_decisions", {})
    for iid in incident_ids:
        decisions.setdefault(iid, {"status": STATUS_PENDING, "assigned": None, "note": "", "time": None})
    state.setdefault("triage_audit", [])


def record_decision(state: dict[str, Any], incident_id: str, status: str, assigned: str, note: str = "", operator: str = "PROCIVY operator") -> None:
    """Store an operator decision and append it to the audit log."""
    stamp = datetime.now().strftime("%H:%M:%S")
    state["triage_decisions"][incident_id] = {"status": status, "assigned": assigned, "note": note, "time": stamp}
    state["triage_audit"].insert(
        0, {"time": stamp, "incident": incident_id, "decision": status, "assigned": assigned, "operator": operator, "note": note}
    )


def reset_decisions(state: dict[str, Any]) -> None:
    """Clear all operator decisions and the audit log."""
    state.pop("triage_decisions", None)
    state.pop("triage_audit", None)

ARCHIVO 8: scripts/verify.py
Rol: Script automatizado de verificación pre-presentación (prueba modelo ML,
     alertas offline, motor de triaje y ejecución headless completa en Streamlit).
--------------------------------------------------------------------------------
```python
"""Pre-demo verification for Yucatán EWRS.

Checks that:
  1. The ML model trains, saves, reloads and predicts sane values.
  2. The fallback alert generator works with no API key (all levels, SMS <= 160).
  3. The triage engine scores and allocates incidents.
  4. ``app.py`` compiles and runs end-to-end in Streamlit's headless AppTest.

Usage:  python scripts/verify.py
"""

from __future__ import annotations

import os
import sys
from pathlib import Path

ROOT = Path(__file__).resolve().parent.parent
sys.path.insert(0, str(ROOT))

# Guarantee the "no API key" path regardless of the local .env.
for var in ("GEMINI_API_KEY", "OPENAI_API_KEY"):
    os.environ[var] = ""


def check(label: str, condition: bool) -> None:
    """Print a pass/fail line and abort on failure."""
    print(f"  {'PASS' if condition else 'FAIL'}  {label}")
    if not condition:
        sys.exit(1)


def verify_model() -> None:
    from models.risk_model import ARTIFACT_PATH, Scenario, load_model, predict_municipality_risks, train_model

    print("[1] ML risk model")
    art = train_model(save=True)
    check(f"trained RandomForest (R²={art['metrics']['r2']:.3f}, MAE={art['metrics']['mae']:.2f})", art["metrics"]["r2"] > 0.8)
    check("artifact saved with joblib", ARTIFACT_PATH.exists())
    art = load_model()
    df = predict_municipality_risks(Scenario(5, 450, 5.0, "North Coast"), art)
    check("8 municipalities predicted", len(df) == 8)
    check("scores within 0–100", df["risk_score"].between(0, 100).all())
    check("3 risk drivers per municipality", all(len(f) == 3 for f in df["top_factors"]))
    calm = predict_municipality_risks(Scenario(1, 60, 0.3, "East Coast"), art)
    check("Cat 5 scenario riskier than Cat 1", df["risk_score"].mean() > calm["risk_score"].mean())


def verify_alerts() -> None:
    from models.risk_model import Scenario, load_model, predict_municipality_risks
    from services.alert_generator import CHANNELS, LANGUAGES, SMS_MAX_CHARS, STATUS_FALLBACK, generate_alerts, llm_available

    print("[2] Alert generator (no API key)")
    check("no API key detected", not llm_available())
    scenario = {"category": 4, "rainfall_mm_24h": 320.0, "storm_surge_m": 3.5, "landfall_zone": "West Coast"}
    df = predict_municipality_risks(Scenario(**scenario), load_model())
    for level in ("Critical", "High", "Moderate", "Low"):
        for _, row in df.iterrows():
            profile = row.to_dict() | {"risk_level": level}
            res = generate_alerts(profile, scenario, online=True)
            assert res.status == STATUS_FALLBACK, res
            for lang in LANGUAGES:
                for ch in CHANNELS:
                    text = res.alerts[lang][ch]
                    assert text and "{" not in text, (level, lang, ch, text)
                assert len(res.alerts[lang]["sms"]) <= SMS_MAX_CHARS, res.alerts[lang]["sms"]
    check("fallback used for all 4 levels × 8 municipalities × 3 languages × 3 channels", True)
    check("all SMS <= 160 characters and placeholders filled", True)
    offline = generate_alerts(df.iloc[0].to_dict(), scenario, online=False)
    check("Offline / Demo Mode forces fallback", offline.status == STATUS_FALLBACK)


def verify_triage() -> None:
    from services.triage_engine import load_incident_data, score_incidents, suggest_allocation

    print("[3] Triage engine")
    incidents, brigades = load_incident_data()
    queue = suggest_allocation(score_incidents(incidents), brigades)
    check(f"{len(queue)} incidents scored and ranked", queue["priority_score"].is_monotonic_decreasing)
    check("every incident has an AI suggestion", queue["ai_suggestion"].notna().all())


def verify_app() -> None:
    from streamlit.testing.v1 import AppTest

    print("[4] Streamlit app")
    compile((ROOT / "app.py").read_text(encoding="utf-8"), "app.py", "exec")
    check("app.py compiles", True)
    at = AppTest.from_file(str(ROOT / "app.py"), default_timeout=120).run()
    check("app.py runs headless without exceptions", not at.exception)
    gen = next(b for b in at.button if b.label.startswith("📣"))
    gen.click().run()
    check("Generate Alert works (offline)", not at.exception)
    for t in at.toggle:
        t.set_value(True)
    at.run()
    check("outage + offline toggles render without exceptions", not at.exception)
    approve = next(b for b in at.button if b.label == "Approve")
    approve.click().run()
    check("HITL approve action works", not at.exception and len(at.session_state["triage_audit"]) == 1)


if __name__ == "__main__":
    verify_model()
    verify_alerts()
    verify_triage()
    verify_app()
    print("\nAll checks passed ✅")
```

ARCHIVO 11: Dockerfile
```dockerfile
# Yucatán EWRS – Streamlit demo image
FROM python:3.11-slim

ENV PYTHONDONTWRITEBYTECODE=1 \
    PYTHONUNBUFFERED=1 \
    PIP_DISABLE_PIP_VERSION_CHECK=1 \
    STREAMLIT_BROWSER_GATHER_USAGE_STATS=false

WORKDIR /app

# Dependencies first so this layer is cached across code changes
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

COPY . .

# Bake the trained model into the image so container startup is instant
RUN python -m models.risk_model

# Run as an unprivileged user
RUN useradd --create-home --uid 1000 appuser && chown -R appuser:appuser /app
USER appuser

EXPOSE 8501

# python:slim has no curl, so probe the health endpoint with the stdlib
HEALTHCHECK --interval=30s --timeout=5s --start-period=20s --retries=3 \
    CMD python -c "import urllib.request,sys; sys.exit(0 if urllib.request.urlopen('http://localhost:8501/_stcore/health', timeout=4).status == 200 else 1)"

CMD ["streamlit", "run", "app.py", "--server.address=0.0.0.0", "--server.port=8501", "--server.headless=true"]
```

# Yucatán EWRS – Hurricane Early Warning & Response System

A Streamlit MVP built for a Digital Economy presentation. It shows how an AI layer (hyperlocal ML risk scoring, multilingual LLM alerts and human-in-the-loop triage) can sit on top of the simple protocols Yucatán already uses: Cell Broadcast, community radio, printed maps and drainage maintenance.

> **Works 100% offline.** If no API key is set, the LLM call fails or times out, Offline / Demo Mode is on, or a telecom outage is simulated, the app switches to the pre-approved templates in `data/fallback_alerts.json`.
